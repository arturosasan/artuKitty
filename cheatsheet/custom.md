# Custom Commands

| Command | Action |
|---------|--------|
| `Ctrl+F` | Fuzzy find file and open in editor |
| `Ctrl+G` | Open lazygit |
| `mkcd <dir>` | Create directory and cd into it |
| `ex <file>` | Extract any archive |
| `fkill` | Fuzzy kill process |
| `serve [port]` | Quick HTTP server |
| `cheat [topic]` | Browse cheatsheets |
| `cheat-add <topic> <key> <desc>` | Add cheatsheet entry |
| `z <dir>` | Smart cd (zoxide) |
| `reload` | Reload zsh config |
| `path` | Show PATH line by line |
| `weather` | Show weather |
| `myip` | Show public IP |
| `dirsize` | Show directory sizes (dust) |
