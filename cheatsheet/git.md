# Git Shortcuts

| Shortcut / Command | Action |
|--------------------|--------|
| `Ctrl+G` | Open lazygit |
| `gs` | git status |
| `gc` | git commit |
| `gp` | git push |
| `gpl` | git pull |
| `gsw` | git switch |
| `lg` | lazygit |
| `ghb` | Open repo in browser |
| `gdm` | git diff main...HEAD |
